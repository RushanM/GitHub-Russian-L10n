Проект по русской локализации («русификатор») сайтов/страниц GitHub, реализованный в виде пользовательского сценария для Tampermonkey и его аналогов (например, [Violentmonkey](https://addons.mozilla.org/en-US/firefox/addon/violentmonkey/)).

**Сценарий на стадии прототипа и не переводит абсолютно весь текст сайтов/страниц.**

## Установка

1. Установите расширение Tampermonkey или его аналог (например, [Violentmonkey](https://addons.mozilla.org/en-US/firefox/addon/violentmonkey/)).
2. Откройте ссылку на сценарий c [GitHub](https://github.com/RushanM/GitHub-Russian-L10n/raw/refs/heads/master/github-russian-l10n.user.js) или [Greasy Fork](https://greasyfork.org/ru/scripts/515487-github-russian-localization).
3. Установите сценарий.
4. Обновите страницу GitHub, если она была открыта.
5. Готово!

## Вклад в перевод

Проект открыт ко вкладам через запросы на слияния (pull requests). Вам могут пригодиться знания GitHub, JavaScript, CSS, Mozilla Project Fluent и HTML. Если запрос на слияние будет неудовлетворительным, об этом будет сообщено.
